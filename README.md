# PicoT HEMS

**Planning, Intelligence, Coordination, Orchestration & Transparency.**

PicoT HEMS is a modular, explainable and Home Assistant-oriented Home Energy Management System.

The capital **T** represents **Transparency** as the unifying principle across Planning, Intelligence, Coordination and Orchestration.

## Current phase

Architecture and design.

## Active work

- DOC-002 Design Specification RC3 migration
- Capability & Health Layer documentation
- Learning Layer integration
- Dashboard and explainability design

## Core principles

- Safety First
- Verify, Don't Assume
- Evidence over Assumption
- Explain Every Decision
- Deterministic by Design
- Modularity over Complexity
- Graceful Degradation
- Platform Independence
- Closed-loop Control
- Clarity Above Cleverness

## Platform strategy

Home Assistant is the primary and only target platform during design, implementation and stabilisation. Homey support is not a parallel goal and may only be considered after PicoT is successful, stable and maintenance-friendly on Home Assistant.
