# ADR-037.23 - Stable running charge and minimum optional improvement

Status: ACCEPTED - Alex approved the concrete repair on 6 October 2026.
Implementation: IMPLEMENTED locally; CI, release and live verification remain separate.

This explicitly supplements ADR-027 and ADR-037.12/.15/.16. The canonical
Candidate/Evaluation/Builder chain remains the sole planning authority.

Candidate Generation preserves a running daily main grid-charge block through
its admitted end, irrespective of household load quality. Actual 100% SOC
releases the constraint. Necessary recovery may continue or extend charging.
Explicit manual recalculation remains an exception. Safety, technical limits,
invalid incumbents and unavailable required evidence retain their normal handling.
Optional PV/SOC/net-balance reductions are deferred while that block runs.

For an optional grid reduction, Evaluation admits a replacement only when its
producer-derived financial improvement is at least EUR 0.01. This is a minimum
benefit, not an equality tolerance. A shorter grid duration or lower-priority
objective cannot bypass it. An invalid incumbent cannot be retained by this gate.
Initial planning, necessary shortfall repair, manual recalculation, bridges and
initial market admission do not use this minimum.

For main-charge acquisition outcomes in EUR/kWh-stored, Candidate Generation
multiplies the rate improvement by the SAME remaining daily goal in kWh:
usable capacity minus the fresh measured stored energy. This reference-scale
benefit does not value differing future inventories or claim realised savings.
For a complete market recovery comparison already expressed in EUR, use its
existing financial-result difference. Missing comparable financial evidence
does not prove an optional benefit. Raw outcomes are unchanged; the explicit
benefit and minimum-improvement admission record are diagnostic evidence.

This supersedes the unconditional shorter-duration preference of ADR-037.16
ONLY for optional grid reductions below the minimum. The full 100% goal,
reserve requirements, chosen Solcast basis and market measurement guard remain.
No BMS taper model is introduced in this first repair. Rollback is limited to
these Candidate/Evaluation changes and composition; no stored plan migration.
