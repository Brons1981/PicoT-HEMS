# V2ADR-064.1 — Independent EV regulation shadow observer

Status: Accepted for observer-only implementation, 2026-10-08.

The user authorized implementation and offline verification of measurement
freshness, noise suppression and fallback, following the EV-exclusion review.
Energy Devices owns the observer, separately from HEMS and its planning chain.
This narrowly extends V2ADR-064's allowed observations to explicitly configured
RAW grid and signed storage reports. It does not grant actuation authority,
planning authority, ownership of storage modes, or shared P1 publication.

Publish only `sensor.picot_ev_regulation_shadow`, disabled by default. Source
reports require timezone-aware `last_reported`, finite power and explicit units.
Missing, future, old or skewed reports produce an unavailable candidate rather
than fabricating zero or treating a fetch as a fresh measurement. Observer
publication is not an actuator emergency stop.

Demand before storage is RAW minus signed storage power. Exclude only the EV
portion of positive demand. Preserve genuine export. Conservatively round
permitted demand towards zero and suppress small increases away from neutral;
pass reductions/sign changes and large changes immediately. Without EV, return
RAW exactly. These research bounds need live shadow validation.

Active shared-P1 replacement is not part of this slice. It requires a separately
verified consumer freshness/stop contract: RAW fallback cannot repair stale
storage feedback and the existing one-minute unavailable stop is insufficient
for the investigated failure. Do not wire the shadow entity to @gielz or HEMS.
