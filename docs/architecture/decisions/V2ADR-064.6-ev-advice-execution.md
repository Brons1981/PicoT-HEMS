# V2ADR-064.6 - Explicit acceptance and automatic EV execution

Status: implemented locally, not released or installed.

HEMS remains the only economic planner. Energy Devices can accept one ready or
provisional contiguous advice window using execute_advice and the displayed
session_id, request_revision and generated_at. Acceptance confirms the cable is
inserted; BMW cable detection is not required. The UI explains that provisional
prices may change and that acceptance fixes this window.

Acceptance is atomic under the existing session lock and persisted in SQLite.
It rejects stale, changed, cancelled, incomplete or expired advice, validates
energy against fixed power and duration, and forbids a second open session.
A start up to 60 seconds ago is allowed for transport/UI latency; its original
end is retained. Retry of the same active acceptance is idempotent. The request
becomes accepted and cannot accept subsequent HEMS replies. Its UUID is reused
for confirmed demand; the full accepted advice is retained on the session.

The existing one-second physical executor is the sole switch owner. It keeps
the plug off before the window, turns it on within the window, and stops at its
end or cancellation. It persists command intent before dispatch, retries no
faster than ten seconds and requires a known switch state before turning on.
Restart loads the original window without requiring fresh advice. Restart after
the end never turns on. Manual switch-off during charging pauses execution;
explicit Resume remains bounded by the original end. No split-slot cycling,
automatic economic replanning or latest-start fallback is introduced.

Confirmed demand uses the existing v1 session transport, once, with battery
support disabled to preserve the advice's battery-excluded assumptions. Legacy
manual planning cannot mutate an accepted window; cancel and request a new one.
Meter integration and low-power completion remain existing behavior. End of the
window ends execution, not proof of full BMW SOC: the UI shows estimated
remaining kWh after execution. A service outage or manual pause can leave energy
undelivered, and the deadline is never silently extended.

Verification: execution tests cover restart, timed on/off, pre-start off,
cancellation, manual pause, duplicate acceptance, stale/revised/cancelled advice
and inconsistent energy. Existing request and physical session suites pass.
Actual BMW charging remains an installation check; this change does not operate
the user's live plug or modify the current session.
