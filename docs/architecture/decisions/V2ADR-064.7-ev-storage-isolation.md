# V2ADR-064.7 - EV storage isolation

Status: accepted by Alex on 2026-10-17; release requested for HEMS dev.301
and Energy Devices dev.9. Installation and live verification are separate.

All EV sessions exclude home-battery support, not only accepted advice windows
from V2ADR-064.6. Any earlier permission to support EV demand from storage is
superseded. Producers publish exclusion; Planning Input preserves it independently
of corrected-meter availability. Missing measurement is not zero demand and must
not create duplicate household forecasts.

The existing execution boundary enforces exclusion while PicoT owns automatic
control. Without fresh corrected-meter proof, known EV activity prevents battery
discharge; NOM becomes charge-only when valid, otherwise Standby. Fixed discharge
cannot rely on meter correction and is blocked during known EV activity. The
guard survives restart and plan replacement until fresh physical zero evidence.
Manual ownership remains unchanged; this is software polling, not a hardware
interlock. The simulator applies the same excluded-demand constraint.

The existing optional grid-reduction comparison may review a strictly future
main window using fresh SOC state and explicit future-state evidence without
inventing future PV actuals. The unchanged incumbent projection supplies a shared
future refill deficit for economic comparison. Current SOC of 100% must not make
future acquisition savings zero. Canonical candidates, Evaluation, Plan Builder,
daily goals, reserve, running-owner protection and EUR 0.01 minimum benefit remain
authoritative. Active unknown extra household load blocks this optional review.
