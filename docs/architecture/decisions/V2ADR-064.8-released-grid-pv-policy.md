# V2ADR-064.8 - PV-aware released grid intervals

Status: accepted by Alex on 2026-10-17; release dev.302 requested; installation and live verification remain separate.

This supersedes the unconditional NOM baseline for removed own grid-charge
intervals recorded in the 2026-09-15 observation fixes. A released interval uses
NOM only if the configured Solcast planning basis exceeds total household demand
(including battery-excluded EV demand) by more than the existing 1e-6 Wh numerical
tolerance. Otherwise it uses household support only (Alleen slim ontladen).

The feasibility trial, retained-schedule challenger and explicit market-revision
seed use the same rule. The configured PV basis is selected through the shared
simulator function; no second forecast or UI policy is introduced. Evaluation
still compares complete paths, including source policy, reserve and daily goals.
The exact incumbent, other owners, running-charge protection, EV execution guard
and explicitly retained PV windows are unchanged. Standby is not substituted.

Existing persisted NOM intervals are not relabelled in place. New admitted plans
use this policy; a user-requested recalculation can rebuild an existing layout.

The pre-change diagnostic comparison proved that the eight released night
quarters have zero PV in all scenarios and identical physical flows under NOM
and household support only. Tests additionally cover configured lower, midpoint,
central and upper selection, including exactly zero surplus and retained lineage.
