# V2ADR-067 - Complete optional route comparison and visible decision evidence

Status: Accepted scope - Alex requested repair and dashboard explanation on 31 October 2026.

The 18:45 diagnostic replay proves that an optional SOC/PV grid reduction can
change the overnight bridge as well as the refill window. An acquisition-rate
improvement then need not be a saving for the complete changed route.

For optional `DailyMainPVSurplusTrigger` revisions with a valid incumbent,
Candidate Outcome Production supplies total remaining-horizon cash results in
EUR. Incumbent and alternatives use the same fresh snapshot, horizon and end
inventory. Differing horizon or terminal stock is explicitly incomparable and
cannot justify optional replacement. No salvage value or fictitious stock price
is assigned. Raw acquisition figures remain diagnostic provenance.

This supersedes the rate-scaled benefit clause of ADR-037.23 for this optional
revision case only. The existing minimum of EUR 0.01 remains an Evaluation
admission condition. Negative, zero and subcent benefits retain the valid plan.
Initial acquisition selection, explicit recalculation, bridge recovery and
market recovery comparison retain their existing contracts. An invalid incumbent
cannot be protected by the financial gate or the new equal-stock requirement.

The frozen ADR-017/024/026/027/032/033 ownership boundaries remain: Candidate
Generation simulates/produces outcomes; Evaluation chooses; Builder copies;
Store admits; UI projects. There is no new optimizer, forecast policy, switching
threshold, device command, daily-goal reset or automatic EV demand assumption.

The dashboard shows the actual last admitted selection/retention, comparison
period, comparable total costs and producer-derived benefit where available,
minimum improvement, SOC, solar basis, household forecast and confirmed EV input.
An acquisition price is never labelled total savings. An unpublished challenger
is never labelled the active plan. No comparison means an explicit absence of
evidence, not invented zero costs. Explanation reuse requires identical plan/path
identities and retains its original assessment timestamp. A bounded separate
display cache preserves this evidence across restart; it never feeds planning or
execution. Missing, corrupt, future-dated or mismatched historic evidence is not
used. A pre-upgrade plan without saved explanation remains explicitly unexplained
until a new comparison is available.

Rollback is the producer optional flag, its pipeline wiring and read-only UI
projection. Existing saved plans and device/control contracts require no migration.
