## Decisions

### Transparency and trust

Transparency is the foundation of PicoT. Trust is the result.

The design sequence is:

Transparency → Explainability → Evidence → Deterministic Behaviour → Diagnostics → Trust

### GitHub as Single Source of Truth

GitHub is the official project record. Chats are the working space.

What is not recorded in GitHub is not an official PicoT HEMS project decision.

### FULL SYNC workflow

Every development session starts with a FULL SYNC that reads the current GitHub state.

Every development session ends with a proposed FULL SYNC report containing:

- subjects discussed;
- accepted decisions;
- documents changed;
- open actions;
- next session step.

After user approval, the assistant automatically writes the approved changes to GitHub and explicitly reports the result.

A FULL SYNC can only be called completed after the GitHub write succeeds.

### Session records

Each completed session sync creates or updates a dated development log in `docs/development_log/`.
