### Vision

VISION-001 is accepted with these principles:

- PicoT HEMS is a transparent, deterministic and extensible HEMS platform;
- transparency is the foundation;
- trust is the result;
- no Open Source or licensing decision is made in the vision document.

### Principles

PRINCIPLES-001 is accepted.

The design sequence is:

```text
Transparency
        ↓
Explainability
        ↓
Evidence
        ↓
Deterministic Behaviour
        ↓
Diagnostics
        ↓
Trust
```

Every ADR, CFD and PEP must be checked against the question:

> Does this increase or preserve the transparency of PicoT?

### Roadmap

Operational Validation is split into:

#### Phase 4A — Private Alpha

- approximately 0–6 months;
- one installation;
- Core stabilization;
- no uncontrolled major feature expansion;
- supporting work such as Forecast, dashboards, Config Wizard, diagnostics and documentation is allowed.

#### Phase 4B — Trusted Validation Partners

- approximately 6–12 months;
- two to three selected users;
- varied hardware;
- validate architecture and capability abstraction;
- collect additional real-world diagnostics.

#### Phase 4C — Stable Core

Targeted only after at least one year of practical operation and only when critical bugs, explainability, recovery, diagnostics, documentation and supported-device contracts are stable.

### Diagnostics

Diagnostics are a Core feature, not an afterthought.

The intended direction includes:

- one-click diagnostics export;
- decision-specific export;
- privacy-aware sharing;
- export of planner decisions, capabilities, lifecycle state, mappings, execution, logs, configuration and versions;
- future PicoT Replay functionality for reproducing PlannerDecision, Execution, Evidence and Explainability.

### Platform direction

PicoT is intended to become a wider platform. Device Packs register discovery, semantic rules, capability mappings and adapters. PicoT HEMS consumes capabilities without vendor-specific planner changes.

### GitHub as Single Source of Truth

GitHub is the official project record.

What is not recorded in GitHub is not an official PicoT HEMS project decision.
