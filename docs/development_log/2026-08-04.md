# Development log — 2026-08-04

## GoodWe source correction

PicoT was still reading GoodWe values through Homey-shared entities. The active GoodWe observation was migrated to the direct Home Assistant GoodWe SEMS API entities:

- `sensor.inverter_54200dsn211r0265_vermogen`
- `sensor.inverter_54200dsn211r0265_energy_today`
- `sensor.inverter_54200dsn211r0265_energie`
- `sensor.inverter_54200dsn211r0265_temperatuur`

## Energy-balance telemetry

PicoT now publishes `sensor.picot_self_supply_power` for the Technical View. The initial definition is the household load supplied without grid import, derived from the existing normalized power balance. Runtime tests were updated and the add-on version was raised to `0.1.15`.

- retained the derived house-power line during validation;

- aligned both charts on the same 24-hour time span;

- prepared the price chart to consume PicoT `price_points`, with a temporary Nord Pool fallback until PicoT publishes the complete series.

## PEP-UI-001 extension

PEP-UI-001 now records:

- the paired Energiestromen and Energiebalans charts as cause and result;
