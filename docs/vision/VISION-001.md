# VISION-001 — PicoT HEMS Vision

## Status

Accepted

## Mission

Build a fully transparent Home Energy Management System that earns user trust through explainable, evidence-based, deterministic behaviour.

## Vision

PicoT HEMS is a transparent, deterministic and extensible energy-management platform. It coordinates energy flows and connected devices through stable capability contracts, without hiding decisions behind opaque behaviour.

PicoT is intended to grow into a wider platform in which device-specific PicoT modules and Device Packs can register discovery logic, semantic rules, capability mappings and adapters. PicoT HEMS consumes those capabilities without vendor-specific planner changes.

## Core values

- Transparency before trust.
- Explainability for every meaningful decision.
- Evidence-based behaviour.
- Deterministic operation.
- Capability-driven and vendor-independent design.
- Stable contracts and strict boundaries.
- Diagnostics as a core feature.
- Human control over system behaviour.
- Long-term maintainability.

## What PicoT is

PicoT HEMS is:

- a capability-driven HEMS core;
- a coordinator and orchestrator of energy devices;
- a planner that works from validated facts and explicit rules;
- an explainable system whose decisions can be traced and diagnosed;
- a platform that can be extended through Device Packs and PicoT modules.

## What PicoT is not

PicoT HEMS is not:

- an opaque black-box optimizer;
- a system that invents explanations;
- a vendor-specific planner;
- a safety, security or alarm system;
- a project whose official state depends on chat history.

## Development philosophy

The Core is stabilized before expansion. Infrastructure, contracts, records, diagnostics and tests come before optimization logic. New functionality must respect accepted architecture, dependency boundaries and the project principles.

## Distribution and licensing

No decision about Open Source distribution or licensing is made in this vision document. That strategy remains intentionally open.

## Guiding statement

> Transparency is the foundation. Trust is the result.
