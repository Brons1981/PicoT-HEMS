# PicoT HEMS add-on

Deterministische live-validatieruntime voor PicoT HEMS.

De eerste versie leest een prijsforecast uit Home Assistant en kiest uitsluitend tussen:

- `Alleen slim ontladen`
- `Nul op de meter`

De add-on start standaard in `dry_run` en gebruikt de Home Assistant Supervisor API. Zie `DOCS.md` voor de installatie- en validatiestappen.
